# 4c. Arquitectura de canales: wireframes y user journeys B2B/B2C

> Rúbrica H1-D4 (Logrado): user journeys **avanzados** del portal con diferenciación B2B/B2C.

## Perfiles
| | B2B (institucional) | B2C (público general) |
|---|---|---|
| Quiénes | Hospitales, supermercados, ferias, instituciones | Personas |
| Precio | Lista de precios institucional | Precio público |
| Particularidades | Pedidos por volumen, recurrentes, crédito/OC, vendedor asignado | Compra puntual, pago inmediato |

## Journeys a diagramar
- [ ] B2B: login → catálogo con precio institucional → carrito (volumen) → orden → seguimiento del despacho (con temperatura)
- [ ] B2C: catálogo público → carrito → datos de despacho → orden → seguimiento
- [ ] Consulta o reclamo → la IA lo clasifica → llega al CRM
